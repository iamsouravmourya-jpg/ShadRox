# ShadRox privacy

ShadRox stores your local project files and provider keys on your device.
Provider keys use the operating system's encrypted storage where available.

When you ask an AI provider for help, ShadRox sends the prompt and the project
context you select to that provider. ShadRox account authentication stores the
minimum profile information required for the beta, such as email, name, avatar,
app version, and platform. ShadRox does not sync your project folder to a cloud
workspace.

For deletion or privacy questions, contact the beta coordinator in the private
WhatsApp group. Do not include API keys or project contents in the request.
