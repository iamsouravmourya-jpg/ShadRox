# Security

Please report suspected vulnerabilities privately by contacting the founder directly at
`iamsouravmourya@gmail.com` or via [shadrox.cyou/about](https://www.shadrox.cyou/about).
Include a reproduction, the affected version, and the impact. Do not send
credentials or private project files, and do not disclose an unpatched
vulnerability publicly before a fix is shipped.

This beta runs local commands and previews in the folder you open. Use trusted
folders, keep backups, and do not approve commands you do not understand.
