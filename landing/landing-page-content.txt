SHADROX LANDING PAGE — CONTENT BRIEF
====================================

POSITIONING
-----------
ShadRox is a desktop coding workspace for people who want their project files, editor, AI chat, local preview, and terminal together in one app.

Keep the promise grounded: projects are worked on locally, while prompts and the selected code context are sent to the AI provider when the user asks for AI help. Do not claim that code is never uploaded or that ShadRox has cloud project sync. A Google account is required to use the app; there is no paid plan yet.

FEATURE SECTION
---------------
Section heading:
Everything around the code, together.

1. A workspace rooted on your machine
Open a local project folder, browse files as you need them, and save edits back to the project on disk.

2. AI help that fits the task
Ask Gemini or Groq for help with Code, Plan, or Complex workflows. Bring your own provider key, and review AI-proposed file changes before applying them.

3. Preview without leaving the workspace
View static sites and supported Node-based web projects in an in-app preview. Choose among detected nested projects and approve managed run or install actions.

4. A terminal in the project folder
Use an interactive terminal alongside your files and preview. Commands run with your computer account's permissions, so you stay in control of what you execute.

------------

Choose a project folder from your computer.

PRIVACY / DATA FLOW
-------------------
Section heading:
Local project workflow, clear AI data flow.

Copy:
Your project folder is opened and edited on your computer. When you send a message to AI, the prompt and the project context included with that request are sent to the Gemini or Groq provider you selected. You can use your own provider key; it stays on your device in an encrypted local store and is never sent to ShadRox. Signing in with Google creates an account that holds only email, name, avatar URL, app version, and platform. Project files are never uploaded to ShadRox.

Short callout:
Local files. Provider-powered AI. Minimum account data.

Do not shorten this to “your code never leaves your device” or “zero data upload.” Those statements would be inaccurate when AI features are used.


PREVIEW SUPPORT NOTE
--------------------
Heading:
Preview the web projects you are working on.

Copy:
ShadRox can serve static sites and launch detected Node-based web projects with supported package scripts. It is not yet a universal runtime for Python, Go, PHP, Java, or .NET backends. Some apps also restrict embedding in previews.


BETA STATUS / FAQ
-----------------
Can I download ShadRox now?
Yes. The Download for Windows button installs the latest beta (currently 0.0.1) on Windows 10 or 11, 64-bit. No form or approval is needed. Windows may show a SmartScreen warning because the build is unsigned: choose More → Run anyway.

Do I need a ShadRox account?
Yes. On first launch the app asks you to continue with Google, opens the browser, and receives a session. Only email, name, avatar URL, app version, and platform are stored. There is no password and no subscription.

How do updates work?
The app checks for a newer release at startup and downloads it in the background; the update installs on restart or quit. The page's download link always points at the latest release.

Does ShadRox store my project in the cloud?
The desktop workspace opens and edits project files locally. There is no ShadRox cloud project sync. AI requests send the prompt and included project context to the selected AI provider.

Where is my AI provider key stored?
On your device, in an encrypted local store. ShadRox servers never receive it. The provider may charge for usage.

Which AI providers are supported?
The current app supports Gemini and Groq. Provider availability, model access, and usage charges depend on your provider account and key.

Can I preview any project?
Static sites and supported Node-based web projects are the current focus. Other backend runtimes are not supported yet, and some sites may block embedded previews.

Are paid plans available?
No. The beta is free; AI usage is billed by your provider under your own key.

Is the installer production-ready?
It is a beta build. It is not code-signed, so Windows may warn. Only claim a platform is ready after its latest installer has been built and tested on a clean machine.
