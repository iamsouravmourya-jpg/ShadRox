How it works

From folder to commit, in three steps.

1

Open a folder

Pick any local project. ShadRox builds a compact repo map and loads your rules.

2

Ask, then review

Chat, press Ctrl+K or run an agent. Every proposed change shows up as a diff first.

3

Run & commit

Preview it live, test in the terminal, and commit with an AI-written message.

The agent

An AI that shows its work.

Bounded, reviewable and honest about its limits. Nothing is written silently.

Reads first. Then proposes.

Multi-round tool use with native provider calls where supported and a text-protocol fallback. Every request carries a compact repo map.

  • Read-only tools: list, read, search, diagnostics, Git, outlines
  • Edits go through a patch, review and apply pipeline
  • Unsafe edits are held for review, never silently written

Plan. Patch. Verify. Repair.

Big goals become a task DAG of milestones. Each is verified, and failures get a repair brief. Still beta, so review the results.

  • Verified with diagnostics and an optional approved command
  • Configurable repair attempts per milestone
  • Unrecoverable failure rolls back to the checkpoint

A small team, with boundaries.

A Coordinator splits the goal and assigns specialists. Each brief carries file ownership so agents stay out of each other’s way.

  • Shared bounded tool loop and guarded patch path
  • The Tests role will not weaken tests to make them pass
  • Reviewer reads and reports, changes nothing

Privacy

Local-first.
By design.

ShadRox edits real files on your disk. Only the prompt and context you choose go to the provider you picked, and your key never touches ShadRox servers.

💻 Your computerfiles · key · rules
🧠 Your providerprompt + context
1

🗂️ Files stay on your computer

No cloud project sync, ever.

2

🔐 Keys in OS-backed encrypted storage

Sent straight to your provider, not to us.

3

✅ Approval-gated commands

Run in a credential-scrubbed environment.

4

🧾 Reviewable changes

Unsafe patches are held for review.

Beta, and honest about it.

ShadRox is not a mature replacement for a general-purpose IDE yet. It is a fast-moving solo project, and we would rather tell you what to expect than oversell it.

  • Review every AI diff and keep Git or backups for important work
  • Windows builds are unsigned, so SmartScreen may show a warning
  • Google sign-in is required to enter the app
  • Preview support depends on your project and installed runtimes
